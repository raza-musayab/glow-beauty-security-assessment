Project Scope – Glow Beauty Salon

1. Project Information

- Project Name: Security Assessment of Glow Beauty Salon Web Application
- Client: Glow Beauty Salon
- Intern: Musayab Raza
- Technology: Cyber Security
- Project Level: Intermediate
- Task: 1 – Scope and Rules of Engagement

2. Project Overview

Glow Beauty Salon requires a security assessment of its web application. This project aims to identify potential security weaknesses in a controlled and legally authorized laboratory environment.

The assessment will use PortSwigger Web Security Academy as the practice platform.

3. Project Objectives

- Identify potential web application vulnerabilities.
- Understand the application's attack surface.
- Assess authentication and authorization.
- Examine input validation.
- Review application security.
- Document findings and recommendations.

4. Target Environment

- Practice Platform: PortSwigger Web Security Academy
- Platform URL: https://portswigger.net/web-security
- Testing Environment: Authorized practice laboratory.
- Selected Lab: To be recorded after selecting an actual lab.

5. Application Features to Consider

The assessment will use the following fictional beauty salon business requirements as its context:

- Customer registration and login.
- Appointment booking.
- Beauty service listings.
- Customer information.
- Staff accounts.
- Administrative dashboard.
- Contact forms.

These are proposed business features, not a claim that the selected training lab contains all these functions.

6. In-Scope Activities

- Application navigation.
- Identifying application endpoints.
- Authentication assessment.
- Authorization assessment.
- Input validation assessment.
- SQL injection testing in authorized labs.
- Cross-Site Scripting testing in authorized labs.
- Session management assessment.
- Reviewing HTTP requests and responses.

7. Out-of-Scope Activities

- Attacking real websites without permission.
- Accessing unauthorized accounts.
- Denial-of-Service attacks.
- Stealing customer information.
- Deleting or modifying real data.
- Phishing real employees.
- Testing third-party systems without permission.

8. Tools

- PortSwigger Web Security Academy.
- Burp Suite Community Edition.
- Web Browser.
- GitHub.
- OWASP Top 10 reference.

9. Safety Requirements

All testing will take place within authorized practice laboratories. Only fictional data will be used. Testing will follow the platform's rules and applicable authorization boundaries.

10. Expected Outcome

A documented project scope that establishes the legal testing environment, assessment objectives, boundaries, and preparation for the next project tasks.
