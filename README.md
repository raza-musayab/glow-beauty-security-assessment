Glow Beauty Salon – Security Assessment

Project Overview

This project focuses on the security assessment of a web application for Glow Beauty Salon.

The assessment will be conducted in an authorized laboratory environment using PortSwigger Web Security Academy.

Project Objectives

- Identify web application security vulnerabilities.
- Understand the application attack surface.
- Assess authentication and authorization.
- Review input validation.
- Document security findings.
- Recommend security improvements.

Practice Environment

- Platform: PortSwigger Web Security Academy
- Website: https://portswigger.net/web-security
- Testing: Authorized practice laboratories only.

Project Tasks

1. Scope and Rules of Engagement.
2. Map the Application and Attack Surface.
3. Find and Verify Vulnerabilities.
4. Fix Vulnerabilities and Prove Fixes.
5. Create Detection Rules.
6. Prepare Final Report and Handover.

Project Structure

- docs/: Scope, rules and testing documentation.
- test-data/: Fictional salon sample data.
- screenshots/: Evidence of laboratory setup.

Safety and Legal Notice

All security testing will be performed only on authorized practice laboratories or systems with written permission. No unauthorized real-world systems will be tested.
